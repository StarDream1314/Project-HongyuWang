# 项目文件作用说明

本文件基于对当前目录 `D:\学习\大学生活\科研\Zhang chaohe\Project-HongyuWang\6.final` 的只读扫描整理。

这个仓库主体是一个迁移后的 **ScienceWorld / AOMP-mem 正式验证包**：核心代码在 `codes/experiments/aomp_mem/`，辅助检查和画图脚本在 `codes/scripts/`，`results/`、`data/`、`figs/`、`certificate/` 主要是冻结结果、数据和证书产物。

## 核心 Python 包

- `codes/experiments/aomp_mem/__init__.py`：导出 AOMP-mem 核心类和函数。
- `codes/experiments/aomp_mem/runtime.py`：统一构建 dataset、LLM client、embedder、executor、method 的运行时工厂。
- `codes/experiments/aomp_mem/scienceworld_support.py`：ScienceWorld 环境支持，负责 Java/Py4J/JAR 路径、gold path 匹配、官方环境创建。
- `codes/experiments/aomp_mem/prepare_phase1_datasets.py`：把 AIME、AlfWorld、ScienceWorld、MMLU 原始数据转成统一 JSONL 任务格式。
- `codes/experiments/aomp_mem/rebuild_phase1_summary.py`：从每次实验产物重建 Phase 1 汇总 CSV。
- `codes/experiments/aomp_mem/certificate_eval.py`：离线校准 MQC/OLE 相关证书，并做 AC-16 检查。
- `codes/experiments/aomp_mem/verify_official_alignment.py`：用官方评分规则复查 AIME/MMLU 预测结果。
- `codes/experiments/aomp_mem/summarize_official_alignment.py`：汇总多个 official-alignment 检查结果。
- `codes/experiments/aomp_mem/verify_scienceworld_replay.py`：把 ScienceWorld 预测动作放回官方环境 replay 验证。
- `codes/experiments/aomp_mem/verify_scienceworld_candidate_replay.py`：对非泄漏候选 variation 全量 replay，给 optimistic/conservative 成功率。
- `codes/experiments/aomp_mem/analyze_scienceworld_benchmark_alignment.py`：分析 ScienceWorld benchmark task 是否文本对齐、是否存在隐藏实体或表面偏移。
- `codes/experiments/aomp_mem/build_scienceworld_benchmark_subset_manifest.py`：根据 alignment CSV 构造保守 benchmark manifest。
- `codes/experiments/aomp_mem/annotate_scienceworld_benchmark_subset_manifest.py`：把 replay 结果标注回 benchmark manifest。

## core 目录

- `codes/experiments/aomp_mem/core/__init__.py`：导出核心工具。
- `codes/experiments/aomp_mem/core/memory.py`：定义 `MemoryEntry`、`FeedbackRecord`、`MemoryStore`，即经验记忆的数据结构和容量管理。
- `codes/experiments/aomp_mem/core/retrieval.py`：哈希 embedder、余弦相似度、top-k 检索。
- `codes/experiments/aomp_mem/core/embedding.py`：可插拔 embedding 协议和 sentence-transformers embedder。
- `codes/experiments/aomp_mem/core/llm_interface.py`：Mock、Gemini/OpenAI HTTP client、环境变量读取、重试和响应解析。
- `codes/experiments/aomp_mem/core/refinement.py`：准确慢通道的 think/refine/act 深度 refinement 流程。
- `codes/experiments/aomp_mem/core/executor.py`：把检索、scheduler、LLM、memory 更新串起来执行单个任务。
- `codes/experiments/aomp_mem/core/drift.py`：性能漂移和相似度 warning 检测。

## results 目录中的重复产物模式

`results/` 下的正式结果按 method、seed、schedule 分层，例如：

- `results/adaptive/seed_42/adaptive/`
- `results/cheap_only/seed_42/cheap_only/`
- `results/fixed_low/seed_42/fixed_low/`
- `results/exp3/seed_42/exp3/`
- `results/oracle_high/seed_42/oracle_high/`
- `results/adaptive-ablation study/seed_42/adaptive/`
- `results/cheap_only-ablation study/seed_42/cheap_only/`

每个结果目录通常包含 4 类文件：

- `config.json`：单次运行配置和环境版本，包含 dataset、model、schedule、seed、OLE 开关、预算、prompt mode 等。
- `trajectory_*.csv`：逐任务轨迹，含 `success`、`progress`、`n_cheap`、`n_refine`、`coverage_t`、`precision_t`、`ole_mean_t`、`ole_var_t`、`ole_ucb_t` 等字段。
- `predictions_*.jsonl`：逐任务预测动作和调度/证书 metadata。
- `budget_analysis.csv`：单次运行预算、成本、成功率、平均进度和效率汇总。

## 缓存文件

- `codes/**/__pycache__/*.pyc`：Python 3.13 运行生成的字节码缓存，可重新生成，不是源码。

## 项目整体执行关系

1. `data/` 提供 ScienceWorld 任务和 gold actions。
2. `datasets/` 把数据封装成统一任务接口。
3. `core/` 负责记忆、检索、LLM 调用和 refinement。
4. `schedulers/` 决定每个任务是否使用慢反馈 refinement。
5. `certificate/` 计算 OLE/MQC 证书和质量指标。
6. `evaluation/runner.py` 统一跑实验并写出结果。
7. `codes/scripts/` 负责结果校验、汇总和画图。
8. `results/`、`figs/`、`certificate/` 保存冻结实验输出和论文图表。
